# "Guess first, then see" page (Peace 2026)

> **Educational demos made to show an open-source tool. Not research.**

Open the page: <https://faviovazquez.github.io/nobel-2026-lab/2026/peace/page/> (or open `index.html` from a local copy).

One self-contained page about the 2026 Nobel Peace Prize (Navanethem Pillay, "for her efforts to promote peace and
international law"). It puts two questions to open UCDP data, in two rooms like the film. The visitor guesses with
a slider, then reveals the answer:

1. **How do armed conflicts end?** The share of conflict endings since 1946 that were a peace agreement or a
   ceasefire agreement, then the decade bars and the twist: more conflicts now fade out (low activity), and among
   endings with a clear outcome an agreement or ceasefire is now the most common one. A toggle switches between
   "all endings" and "clear outcomes only". From the [how-conflicts-end toy](../how-conflicts-end/).
2. **Do peace agreements hold?** The share of agreements still quiet five years after the fighting first stopped,
   with its interval from resampling linked conflicts, and the Kaplan-Meier curve drawn in SVG from the JSON. A
   switch shows the strict "from the signature" clock and says why it is lower (fighting that never stopped counts
   as "resumed"). The page says the data cannot rank the agreement types. From the
   [do-agreements-hold toy](../do-agreements-hold/).

Every number in the page's text is read from `data.js`; none is typed into `index.html` (a test checks the HTML
text and every string in the script). The narrator sentences are the toys' `INSIGHTS.md` lines, unchanged. Only
global totals: no conflict, country or place is named. If any input is not `"final"`, a box under the top label says
which one ("Preliminary", or "Placeholder numbers" for the fixtures).

## Open it

Double-click `index.html`, or from this folder: `open index.html` (macOS) / `xdg-open index.html` (Linux).
No server, no network, no external fonts, scripts or images. It works from `file://` and from GitHub Pages. Dark
first (a graphite ground with one warm accent); the light theme follows the system setting or the theme button.

## Files

| file | what |
|---|---|
| `index.html` | the page: HTML, CSS and plain JavaScript in one file; the charts are inline SVG made by the script |
| `data.js` | generated by `build_data.py`; sets `window.NOBEL_PEACE_DATA` (about 10 KB) |
| `build_data.py` | reads the two toys' results JSON and INSIGHTS.md and writes `data.js` (Python 3 standard library only) |
| `run_all.py` | one command: `build_data.py`, then the browser checks, screenshots and `og.jpg` |
| `make_fonts.py` | subsets the two OFL font families into `fonts/` (only needed if the page gains new characters) |
| `fonts/` | IBM Plex Sans and Source Serif 4 subsets (WOFF2), renamed "Peace Page ..."; `OFL.txt`, `OFL-1.1.txt`, `faces.txt` |
| `og.jpg` | 1200x630 share image (the page opened at `index.html#og`) |
| `screenshots/` | `page_{360,768,1440}_{light,dark}.png`, the full page after both guesses |
| `tests/` | `test_build_data.py` (pytest), `test_page.mjs` (headless Chromium) and `test_page.py` (runs it under pytest); `fixtures/` holds copies of the two results files marked `"fixture"` |

## Rebuild

From `2026/peace/` (the toys sit next to the page; `--from` points at results folders anywhere else):

```bash
cd 2026/peace
python3 -m page.run_all                 # ../how-conflicts-end/results and ../do-agreements-hold/results
python3 -m page.run_all --from ENDS_RESULTS HOLD_RESULTS
python3 -m page.run_all --fixtures      # the copies in page/tests/fixtures (the page says "Placeholder numbers")
python3 -m page.run_all --no-browser    # only rebuild data.js
```

`build_data.py` prints the status of each input. A results file with no `"status"` field counts as final.
To refresh the fixtures from the toys: `python3 page/tests/fixtures/make_fixtures.py TOY1_DIR TOY2_DIR`.

## Tests

```bash
cd 2026/peace/page
python3 -m pip install -r requirements.txt
python3 -m pytest -q tests
```

The browser check needs Node 18+ and `playwright-core` with a Chromium build. It defaults to showtime's copies
(`~/.showtime/node/node_modules/playwright-core`, `~/.showtime/browsers`); set `PLAYWRIGHT_CORE` and
`PLAYWRIGHT_BROWSERS_PATH` to use others. It opens the page from `file://` at 360, 768 and 1440 px in light and
dark (one run with reduced motion), makes both guesses, flips both toggles, and checks: the label comes first, the
answers stay hidden until a guess, every number shown is in `data.js`, no network requests, no console errors, no
sideways scrolling, the bundled fonts load, the charts have a title and description, and the credits are there. It
also opens the page with the fixtures and with one toy missing.

## Fonts

IBM Plex Sans (body and numbers) and Source Serif 4 (headings, big numbers, quotes), both under the SIL Open Font
License 1.1, from github.com/google/fonts. `make_fonts.py --src DIR` subsets them to the characters the page uses
(needs `fonttools` and `brotli`); `fonts/OFL.txt` lists the copyright lines.
